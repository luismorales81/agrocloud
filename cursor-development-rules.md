# Mandatory Development Protocol

1. Every new feature must start with a SPEC file inside /docs/specs.
2. No source code may be generated before the SPEC is approved.
3. The assistant must:
   - Create the spec
   - Identify missing business rules
   - Identify architectural risks
   - Ask clarification questions
4. Only after explicit approval can technical design be proposed.
5. Only after technical design approval can code be generated.

Todo el desarrollo debe seguir los lineamientos de **Spec Driven Development (SDD)**.
